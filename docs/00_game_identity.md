# LEXIQUEST GAME IDENTITY & VISION (PHASE P0)

## 1. GAME IDENTITY
* **Tên trò chơi**: LexiQuest: Echoes of Knowledge / Đại Sử Việt
* **Thể loại**: 2D RPG-lite Educational Adventure
* **Nền tảng**: HTML5 Web Game (Client-side Canvas 2D + DOM Overlay)
* **Phong cách đồ họa**: Pixel Art 2D (Tỷ lệ nhân vậtlocked: 48×64 px)

## 2. PLAYER FANTASY
Người chơi hóa thân thành **Kaelen (The Seeker)**, mang theo ngọn lửa thấu hiểu và trượng Cổ Tự Rune, cùng tinh linh đồng hành **Lex** và cậu bé **Sử** du hành qua các cõi tri thức Lexia để giải cứu ký ức lịch sử Việt Nam và khôi phục ngôn từ khỏi sự bóp méo của **Hội Nhàn Nhã (Order of Lethargy)**.

## 3. CORE GAMEPLAY LOOP
```
Explore (WASD) ──► Discover ([E]) ──► Learn (Hội thoại) ──► Apply (Resonance) ──► Restore (Lexaris Glow) ──► Progress
```
1. **Explore**: Di chuyển Kaelen và Lex trên bản đồ 3-quarter.
2. **Discover**: Tiếp cận Mảnh Tri Thức phát sáng, phím `[E]` tự động xuất hiện.
3. **Learn**: Đọc kịch bản hội thoại chuẩn Canon.
4. **Apply**: Vận dụng kiến thức vừa học giải thử thách đố vui **Echo Resonance Trial**.
5. **Restore**: Phản hồi thị giác Cội Nguồn Lexaris bừng sáng, tia ma thuật Beam bắn về trung tâm.
6. **Progress**: Tăng chỉ số thấu hiểu, tự động lưu tiến trình và mở vùng đất mới.
